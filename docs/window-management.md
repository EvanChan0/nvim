## 基础概念

### Neovim 窗口层级

```
┌─────────────────────────────┐
│        Buffer (缓冲区)       │  ← 文件内容
│     ↓                       │
│     Window (窗口)            │  ← 查看缓冲区的视图
│     ↓                       │
│     Split (分屏)             │  ← 将窗口分成多个部分
└─────────────────────────────┘
```

### Tmux Pane vs Neovim Split

```
┌─────────────────────────────────────────┐
│  Tmux Session                           │
│  ┌───────────┬───────────┐              │
│  │ Tmux Pane │ Tmux Pane │              │
│  │           │           │              │
│  │  ┌────┬───┤  (Shell)  │              │
│  │  │Nvim│Vim│           │              │
│  │  │Spl │Spl│           │              │
│  │  └────┴───┤           │              │
│  └───────────┴───────────┘              │
└─────────────────────────────────────────┘
```

**重点：** `Ctrl+hjkl` 可以在所有这些之间无缝移动！

## 导航操作

### 🔵 焦点移动（最常用）

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl + h` | 向左移动 | 跨越 Neovim split 和 tmux pane |
| `Ctrl + j` | 向下移动 | 智能判断边界 |
| `Ctrl + k` | 向上移动 | 智能判断边界 |
| `Ctrl + l` | 向右移动 | 智能判断边界 |
| `Ctrl + \` | 返回上一个窗口 | 快速切换 |

**示例场景：**
```
你在 Neovim 左边的 split，按 Ctrl+h
→ 如果左边是 Neovim split，移动到那个 split
→ 如果左边是 tmux pane，移动到那个 pane
→ 完全无感知！
```

### 🔵 Buffer 切换

| 快捷键 | 功能 |
|--------|------|
| `Shift + h` | 上一个 buffer |
| `Shift + l` | 下一个 buffer |
| `[b` | 上一个 buffer |
| `]b` | 下一个 buffer |
| `<leader>bb` | 切换到上一次的 buffer |
| `<leader>bd` | 删除当前 buffer |

## 窗口大小调整

### 🟢 智能调整（推荐）

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Option + h` | 向左调整 | 智能判断调整哪条分隔线 |
| `Option + j` | 向下调整 | 智能判断调整哪条分隔线 |
| `Option + k` | 向上调整 | 智能判断调整哪条分隔线 |
| `Option + l` | 向右调整 | 智能判断调整哪条分隔线 |

> **macOS 注意：** `Option` 键就是 `Alt` 键

**智能之处：**
```
┌─────────┬─────────┐
│    A    │    B    │
├─────────┤         │
│    C    │         │
└─────────┴─────────┘

在窗口 A 中：
- Option+l → 增加 A 的宽度（移动 A-B 之间的竖线）
- Option+j → 增加 A 的高度（移动 A-C 之间的横线）

自动判断！无需思考！
```

**范围支持：**
```vim
10<Option+h>  " 一次向左调整 10 个单位
5<Option+j>   " 一次向下调整 5 个单位
```

### 🟡 备用方案（手动命令）

如果 Option 键完全失效，可以在 tmux 命令行手动调整：

```bash
:resize-pane -L 3   # 向左
:resize-pane -R 3   # 向右
:resize-pane -U 3   # 向上
:resize-pane -D 3   # 向下
```

按 `Ctrl+Space :` 进入 tmux 命令模式

## 创建和关闭窗口

### 🟣 Neovim Split

| 快捷键 | 功能 |
|--------|------|
| `<leader>-` | 水平分屏（下方新建） |
| `<leader>\|` | 垂直分屏（右侧新建） |
| `<leader>wd` | 关闭当前窗口 |
| `Ctrl+w q` | 关闭当前窗口 |
| `Ctrl+w o` | 只保留当前窗口 |

**示例：**
```
<Space>-   创建水平分屏
<Space>|   创建垂直分屏
```

### 🟣 Tmux Pane

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Space -` | 水平分屏（下方新建） |
| `Ctrl+Space _` | 垂直分屏（右侧新建） |
| `Ctrl+Space x` | 关闭当前 pane |

## 高级操作

### 🔴 窗口位置移动

**Neovim - 移动整个窗口：**

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Shift+h` | 移动窗口到最左边 |
| `Ctrl+Shift+j` | 移动窗口到最下面 |
| `Ctrl+Shift+k` | 移动窗口到最上面 |
| `Ctrl+Shift+l` | 移动窗口到最右边 |

**Neovim - 交换窗口（smart-splits）：**

| 快捷键 | 功能 |
|--------|------|
| `<leader>wh` | 与左边窗口交换 |
| `<leader>wj` | 与下方窗口交换 |
| `<leader>wk` | 与上方窗口交换 |
| `<leader>wl` | 与右边窗口交换 |

**Tmux - 交换 pane：**

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Space >` | 与下一个 pane 交换 |
| `Ctrl+Space <` | 与上一个 pane 交换 |

### 🔴 窗口等分

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+w =` | 所有 Neovim 窗口等高等宽 |

## 📖 实战场景

### 场景1：代码对比

```bash
# 1. 打开两个文件
nvim file1.js

# 2. 在 Neovim 中垂直分屏
<Space>|

# 3. 打开另一个文件
:e file2.js

# 4. 用 Ctrl+h/l 在两个文件间切换
# 5. 用 Option+h/l 调整窗口宽度
```

### 场景2：编辑 + 运行

```bash
# 1. 打开 Neovim
nvim main.py

# 2. 在 tmux 中创建水平分屏（下方运行终端）
Ctrl+Space -

# 3. 在下方终端运行代码
python main.py

# 4. 用 Ctrl+k 回到 Neovim 编辑
# 5. 修改代码后用 Ctrl+j 回到终端
# 6. 按上箭头 + Enter 重新运行
```

### 场景3：多文件编辑

```bash
# 1. 在 Neovim 中打开主文件
nvim main.js

# 2. 水平分屏查看测试文件
<Space>-
:e main.test.js

# 3. 再垂直分屏查看文档
Ctrl+k    # 回到上方窗口
<Space>|
:e README.md

# 现在布局：
# ┌─────────┬─────────┐
# │ main.js │ README  │
# ├─────────┴─────────┤
# │   main.test.js    │
# └───────────────────┘

# 4. 用 Ctrl+hjkl 在三个文件间切换
# 5. 用 Option+hjkl 调整窗口大小
```

## 🎯 常见问题

### Q1: Option 键不起作用？

**macOS Terminal/iTerm2:**
```
Preferences → Profiles → Keys
→ 设置 Left Option key 为 "Esc+"
```

**Ghostty:**
已经默认配置好了，应该可以直接使用。

### Q2: Ctrl+hjkl 卡在 Neovim，不能跳到 tmux？

检查：
1. smart-splits.nvim 已加载（`:Lazy` 查看）
2. tmux 配置已重新加载（`Ctrl+Space r`）
3. tmux 版本 >= 3.0

### Q3: 如何知道我在 Neovim split 还是 tmux pane？

**视觉提示：**
- Neovim split: 分隔线是灰色 `#363636`
- Tmux pane: 分隔线是蓝色 `#7E9CD8`（活动）

### Q4: 忘记快捷键怎么办？

按 `<Space>` 等待 0.5 秒，which-key 会显示所有可用快捷键！
